# Animated Eye Wallpaper

Animated grayscale wallpaper with waving cloth displacement and periodic eye blinking.

## Requirements

- Python 3
- OpenCV
- NumPy
- FFmpeg (h264_nvenc or libx264)
- Hidamari live wallpaper player

## Generation

```bash
python3 render_wallpaper.py
```
